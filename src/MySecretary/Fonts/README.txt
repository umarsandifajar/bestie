Taruh font Plus Jakarta Sans (file statis .ttf, misal PlusJakartaSans-Bold.ttf dan PlusJakartaSans-Medium.ttf)
di folder ini. Otomatis ikut ter-embed saat build (lihat MySecretary.csproj).
Kalau folder ini kosong, aplikasi memakai Plus Jakarta Sans yang terpasang di Windows; kalau tidak ada, jatuh ke Segoe UI.
Unduh: https://fonts.google.com/specimen/Plus+Jakarta+Sans  (pakai folder "static")
