## bestie v1.1.0

Asisten desktop Windows di tepi layar: jam notch, panel fisheye, pengingat sholat, reminder & alarm, to do, Doc Converter, Folder Organizer, dan Batch Watermark.

### Unduh
- **`bestie-v1.1.0-setup.exe`** (disarankan): installer tanpa hak admin, dengan opsi **jalan otomatis saat Windows menyala** dan shortcut Desktop.
- `bestie-v1.1.0-win-x64.exe`: portable, klik dua kali langsung jalan.
- `bestie-v1.1.0-win-x64-lite.exe`: portable kecil, butuh [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).

Mematikan jalan otomatis: Task Manager › Startup apps › bestie › Disable. Uninstall lewat Settings › Apps.

### Default instalasi baru
- Library kosong, hanya menu bawaan. Tambah aplikasi, folder, atau link sendiri di Pengaturan › Library.
- Tema Black, buka panel dengan klik jam, tepi kiri layar mati, pengingat adzan aktif.
- Pomodoro `15,25,45,60`, Timer `5,10,15,30`, durasi awal Timer 5 menit.

### Catatan
- Windows 10 (19041+) atau Windows 11, 64-bit.
- SmartScreen bisa memperingatkan (installer dan `.exe` belum ditandatangani): **More info › Run anyway**. Verifikasi dengan `SHA256SUMS.txt`.
- Config lama tidak diubah.
